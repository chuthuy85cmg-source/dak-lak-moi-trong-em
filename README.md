# Đắk Lắk mới trong em — website mẫu

## Chạy thử trên máy tính
1. Giải nén thư mục `dak-lak-moi-trong-em`.
2. Mở thư mục bằng Visual Studio Code.
3. Mở `index.html` bằng trình duyệt; hoặc cài tiện ích **Live Server** trong VS Code, bấm chuột phải vào `index.html` → **Open with Live Server**.
4. Chỉnh nội dung trong `index.html`, giao diện trong `style.css`, tính năng trong `script.js`.

## Cấu trúc
- `index.html`: cấu trúc và nội dung các mục.
- `style.css`: màu sắc, bố cục, giao diện đáp ứng điện thoại.
- `script.js`: menu, trò chơi trắc nghiệm, tìm kiếm, xem thử audio/video, biểu mẫu minh họa.
- `images/`, `audio/`, `videos/`: thư mục để nhóm thêm tư liệu của mình.

## Đưa website lên GitHub Pages
1. Đăng nhập GitHub, tạo repository mới tên `dak-lak-moi-trong-em`.
2. Đặt repository ở chế độ **Public** (hoặc kiểm tra điều kiện Pages của tài khoản/trường).
3. Tải các tệp trong thư mục dự án lên repository, sao cho `index.html` nằm ngay ở thư mục gốc.
4. Vào **Settings → Pages**.
5. Ở **Build and deployment**, chọn **Deploy from a branch**.
6. Chọn branch `main`, folder `/(root)`, rồi bấm **Save**.
7. Chờ GitHub hoàn tất xuất bản. Đường dẫn thường có dạng:
   `https://TEN-TAI-KHOAN.github.io/dak-lak-moi-trong-em/`
8. Thay `TEN-TAI-KHOAN` bằng tên tài khoản GitHub thật của bạn. Xem đường dẫn Pages thực tế trong Settings → Pages.

## Trước khi nộp đề tài KHKT
- Thay nội dung mẫu bằng thông tin đã kiểm chứng.
- Ghi nguồn cho hình ảnh, âm thanh, video và bài viết; xin phép người xuất hiện trong tư liệu.
- Kiểm tra trên điện thoại và máy tính.
- Lưu ảnh chụp màn hình, nhật ký thử nghiệm, phản hồi người dùng và các lần cải tiến.
- Lưu ý: biểu mẫu hiện là bản minh họa, chưa gửi dữ liệu lên máy chủ. Tệp audio/video được chọn chỉ xem thử trên trình duyệt hiện tại.
